# First GitHub Actions Workflow

## What I Learned

### on:
Defines when the workflow should run.

### jobs:
Contains all jobs in the workflow.

### runs-on:
Defines the operating system used by the runner.

### steps:
Sequence of tasks executed inside a job.

### uses:
Used to run predefined GitHub Actions.

### run:
Executes shell commands.

### name:
Provides readable names for jobs or steps.
